# PR111497 secretless POSIX proof harness

This branch contains validation artifacts only; it is not part of the OpenClaw PR diff and does not change a release or the default branch. The single GitHub-hosted Ubuntu job checks out exact candidate 849b9156c0d8ca5a9fe7d6252edff7a6b68edb16 and pre-retention baseline 20e0ed521c00fd38b1d4d003636fa4ddd3bf2066 with read-only checkout permission and no persisted Git credentials. No application, provider, channel or personal secrets are used.

The recorder uses real Git, SQLite, native POSIX symlinks, owner admission, run-end cleanup and garbage collection in disposable synthetic state. It never installs dependencies, changes tested source, mocks free space, starts a production Gateway, or contacts the synthetic external artifact URL. Baseline RED must be behavioral file loss, never a setup failure. Candidate containment includes an inbound alias, URL-only/outside references, an outbound symlink, all automatic cleanup lanes and the externalization inverse. The upgrade lane seeds a database through the actual frozen-baseline code in one process, then reopens it through the candidate's real Workboard service startup in another process, checks additive table creation and preservation of the complete existing card, then exercises cleanup and the inverse.

Containment runs three fresh two-process fixtures with `--gc-lane idle`, `count`, and `size`. Each must preserve the referenced artifact, then actually remove that same checkout after externalization using the same GC parameters. Only idle advances the service clock, and it disables count/size limits; count and size keep the original clock so idle removal cannot substitute for their eviction. A disabled GC lane cannot pass its own inverse.

Only redacted receipt projections are uploaded as an Actions artifact; raw fixture repositories, databases, configuration and logs are excluded. This proves stable-baseline additive upgrade behavior, not compatibility with unmerged preview table shapes or downgrade artifact safety. Maintainer acceptance remains a separate decision.
